## 二、调研结论：潘达利亚的视觉语言

1. **形制**：曲线屋顶（飞檐起翘）是绝对核心特征，不是直角方盒。屋脊有走兽，檐下有斗拱。
2. **材质**：木构（深棕）、琉璃瓦（金/青）、玉石（青玉绿）、丝绸（朱红/金）、石作（汉白玉）。
3. **氛围**：**迷雾**是第一氛围元素 —— 不是清晰锐利的，而是层层叠叠、远近分明的空气透视。
4. **配色**：青玉绿 + 暖金 + 朱红 + 雾灰蓝，饱和度中高但不刺眼，靠**明度层次**而非高饱和堆叠。
5. **与 Minecraft 的区别**：Minecraft 是「1 米方块 + 16×16 贴图 + 直角」；潘达利亚的官方美术是**曲线、细部密集、材质分层**。

## 三、路线选择：**混合方案（b）+ 贴图升级（c）**

### 为什么不用纯体素（方案 a：更小体素）
把体素单位降到 0.25 格，同样体积的方块数会变成 64 倍。当前 848k 三角面会变成 5400 万，完全不可行。而且**更小的方块仍然是方块**，飞檐的曲线依然要靠阶梯近似，只是阶梯更细 —— 收益远小于代价。

### 为什么不用纯写实（方案 d）
用户明确要求「仍然是像素风」，写实渲染会丢掉像素质感。

### 选定路线：**体素地形 + 精细构件 + 高分辨率像素贴图**

具体三层：

**第一层：体素地形（保留）**
地形、水体、植被、道路仍然用体素 —— 这是沙盒玩法的基础（可破坏/可放置）。

**第二层：非体素精细建筑构件（新增）**
飞檐、斗拱、栏杆、屋脊走兽、塔刹、牌坊额枋改用**低多边形挤出几何体**：
- 飞檐用 `ExtrudeGeometry` 沿曲线路径挤出，得到**真正平滑的起翘曲线**，而不是阶梯
- 斗拱用小型组合几何体，密集排列
- 栏杆用重复的立柱 + 横杆
- 这些构件**不参与体素碰撞**（玩家不能破坏建筑构件），但视觉上大幅提升精致度

**第三层：高分辨率像素贴图（升级）**
- 方块贴图从 **32×32 提升到 64×64**，增加砖缝、木纹、瓦当纹样、石材质感、织物纹理
- 引入**方块变体**：同一材质 3–4 个随机变体，消除大面积重复感
- 保持 `NearestFilter`，维持像素风

### 为什么这条路线更精致

| 维度 | 当前（纯体素 32×32） | 新路线（混合 + 64×64） |
| --- | --- | --- |
| 飞檐曲线 | 阶梯近似，锯齿明显 | 真实平滑曲线 |
| 贴图细节 | 32×32，细节有限 | 64×64，4 倍像素信息 |
| 重复感 | 同材质完全一致 | 3–4 变体随机分布 |
| 建筑细部 | 只能靠方块堆 | 可做斗拱/雀替/挂落等小构件 |
| 氛围 | 静态 | 花瓣/竹叶粒子、香炉烟、旗帜飘动、灯笼摇摆 |

**关键：像素风没有丢** —— 所有贴图仍是逐像素绘制 + nearest 过滤，只是分辨率翻倍、细节层次增加。这更接近「高分辨率像素艺术」（如《八方旅人》HD-2D 的路线），而不是写实渲染。
